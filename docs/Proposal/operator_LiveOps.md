## 1. 목적
출시 후 **게임을 어떻게 유지하고 키울지** 정하는 문서임. 1인 운영 기준이라 작게 시작함.

## 2. 업데이트 주기 (제안)
| 종류 | 주기 | 내용 |
|---|---|---|
| 핫픽스 | 필요할 때 | 치명 버그 · 크래시 |
| 패치 | 2주 | 버그 · 밸런스 (웨이브 마리 수, 코인 수급) |
| 콘텐츠 | 6주 | 보류했던 기능 순서대로: 대장 고블린 → 무기 해금 → 엔드리스 (needFix §6) |

## 3. 지표 리뷰 (매주)
| 지표 | 이상 기준 | 대응 |
|---|---|---|
| D1 재접속률 | 지난주보다 5%p 하락 | 첫 판 웨이브 1 ~ 3 난이도 · 튜토리얼 점검 |
| 웨이브별 도달률 | 한 웨이브에서 30%p 이상 급락 | 그 웨이브 마리 수 · 종류 조정 ([밸런스](planner_Balance.md) JSON) |
| 한 판 평균 시간 | 4분 초과 | 웨이브 수 · 마리 수 줄이기 |
| 크래시율 | 1% 초과 | 핫픽스 |
| 광고 시청률 | 20% 미만 | 보상 크기 · 버튼 위치 점검 |

> 밸런스만 바꿀 때는 JSON만 고쳐서 내보낼 수 있게, 나중에 **원격 설정**(Remote Config) 도입을 검토함 → [F-06](common_needFix.md#8-정할-것)

## 4. 이벤트 캘린더 (예시)
| 이벤트 | 기간 | 규칙 · 보상 | 필요한 작업 |
|---|---|---|---|
| 출시 기념 | 첫 2주 | 코인 1.5배 | 코인 배율 값 (원격 설정) |
| 수류탄 데이 | 주말 | 수류탄만 · 시작 10개, 클리어 시 코인 보너스 | 규칙 플래그 1개 |
| 탄약 절반 도전 | 주 1회 | 예비 탄약 절반 | 규칙 플래그 1개 |

## 5. 패치노트 양식
```
[v1.0.3] 2026-00-00
- 고쳤어요: 체력 팩으로 체력이 100을 넘던 문제
- 바꿨어요: 4웨이브 고블린 수 22 → 18
- 새로 나왔어요: (없음)
```
> 유저용은 위처럼 짧게, 내부용은 변경한 JSON · 문서 ID · 커밋 함께 기록 필요.

## 6. CS 처리
| 문의 유형 | 처리 | 기한 |
|---|---|---|
| 결제했는데 안 들어옴 | 주문번호 확인 → 스토어 기록 조회 → 수동 지급 | 24시간 |
| 환불 요청 | 스토어 환불 정책 안내 (환불은 스토어가 처리) | 24시간 |
| 미성년자 결제 취소 | 법정대리인 확인 서류 → 스토어 환불 절차 안내, 지급 재화 회수 | 3일 |
| 기기 변경 후 기록 없음 | 계정 연동 여부 확인 ([서버](developer_Server_Data.md) §5) | 24시간 |
| 버그 신고 | 기기 · 버전 · 재현 방법 받기 → [QA](tester_Release.md) TC 추가 | 확인 후 답변 |

> CS 연락처(이메일)는 스토어 등록 정보와 게임 설정 창에 같은 주소로 기재 필요.

## 7. 장애 대응
| 등급 | 예 | 공지 | 보상 |
|---|---|---|---|
| 1 (전체) | 실행 안 됨 · 저장 유실 | 즉시 (스토어 · SNS) | 코인 지급 검토 |
| 2 (일부) | 특정 기기 크래시 | 확인 후 | 없음 또는 소액 |
| 3 (경미) | 화면 깨짐 | 패치노트 | 없음 |

## 8. 제재 기준
싱글 플레이 게임이므로 랭킹 · 서버 재화가 생길 때부터 적용함.
| 행위 | 1회 | 2회 | 3회 |
|---|---|---|---|
| 비정상 판 결과 (서버 검증 실패) | 그 판 보상 없음 | 경고 | 랭킹 제외 |
| 결제 악용 (환불 후 재화 사용) | 재화 회수 | 이용 정지 | 영구 정지 |
