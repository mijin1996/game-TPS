## 1. 목적
**출시해도 되는 상태인지** 판정하는 문서예요. 시스템 문서의 예외 처리 표가 그대로 테스트 케이스가 돼요.

## 2. 버그 등급
| 등급 | 기준 | 출시 조건 |
|---|---|---|
| 치명 | 진행 불가 · 결제 오류 · 저장 유실 · 크래시 | **0건** |
| 높음 | 규칙이 의도와 다름 (체력 상한 없음 등) | 0건 목표, 남기면 사유 기록 |
| 보통 | 불편하지만 진행 가능 | 목록 관리 |
| 낮음 | 보기 문제 | 목록 관리 |

## 4. 기기 · 성능 기준 (정할 것 → [F-09](../needFix.md#8-정할-것))
| 항목 | 제안 |
|---|---|
| 최소 사양 기기 | 출시 3 ~ 4년 된 보급형 Android 1종 + 최신 폰 1종 |
| 목표 FPS | 30 (최소) / 60 (권장) |
| 동시 최대 고블린 | 기기 테스트로 정함 (예: 40) |
| 화면 비율 | 16:9 · 19.5:9 · 태블릿 4:3 에서 버튼이 화면 밖으로 안 나감 |
| 최소 OS | Unity 6 지원 범위 안에서 결정 |
